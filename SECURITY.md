# Security Policy

Apphoryn processes untrusted third-party repositories and executable packages. Do not submit vulnerabilities by opening a public issue containing secrets or exploit instructions.

Until a dedicated security contact is configured, contact the repository maintainers privately through GitHub's security advisory mechanism where available. Include the affected component, impact, reproduction details and suggested mitigation. Avoid attaching private keys, access tokens or production data.

Operators should follow `docs/SECURITY.md` before exposing an instance publicly.
